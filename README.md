1. Para adicionar as dependências, use:
    ```bash
    npm install
    ```

2. Execute o restore do Banco de dados:
    - Abra o arquivo `script.sql` no Workbench e execute.

3. Crie o arquivo `.env` com as seguintes chaves:
    ```plaintext
    DB_HOST        = ??????            
    DB_USER        = ??????            
    DB_PASSWORD    = ??????    
    DB_NAME        = ??????          
    DB_PORT        = ??????    
    APP_PORT       = ??????
    ```
